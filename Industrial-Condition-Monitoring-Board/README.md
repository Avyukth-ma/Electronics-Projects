# Industrial Condition Monitoring Board

## Overview

An analog multi-sensor condition monitoring PCB designed during an Analog Electronics internship at Yuken India Ltd.

The project demonstrates analog signal conditioning, amplification, filtering, threshold detection, hysteresis, power supply design, and PCB development using KiCad.

## Sensors

- LM35 Temperature Sensor
- LDR Light Sensor
- Potentiometer (Process Variable Simulator)

## Features

- Temperature monitoring with multi-level indication
- Light monitoring with threshold detection
- Simulated process variable monitoring
- Analog signal conditioning
- Comparator-based decision making
- Schmitt trigger hysteresis
- 5V regulated power supply
- Custom PCB design
