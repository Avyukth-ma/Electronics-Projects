# Design Log

## Day 1 - Project Definition and Architecture

### Objective

Select a suitable analog electronics project that demonstrates the concepts learned during the Analog Electronics internship at Yuken India Ltd.

### Project Selected

Industrial Condition Monitoring Board

### Project Description

A multi-sensor analog monitoring system that acquires signals from multiple sensors, conditions them using analog circuits, and generates visual status indications using LEDs.

The project is designed to emphasize analog signal processing rather than microcontroller-based processing.

### Selected Sensors

1. LM35 Temperature Sensor
2. LDR Light Sensor
3. Potentiometer (used as a simulated industrial process variable)

### Major Functional Blocks

* Power Supply Section
* Temperature Monitoring Channel
* Light Monitoring Channel
* Process Variable Monitoring Channel
* Signal Conditioning Section
* Comparator and Indication Section

### Key Analog Concepts Demonstrated

* Voltage Dividers
* Amplifiers
* Low-Pass Filters
* Comparators
* Schmitt Triggers
* Signal Conditioning
* Sensor Interfacing
* LED Indication Circuits
* Regulated Power Supplies
